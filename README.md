## Hosting
This site is plain HTML, CSS, and JavaScript. It can be hosted on GitHub Pages or any static hosting provider.

### GitHub Pages
1. Push these files to a repository.
2. In repository Settings → Pages, publish from the `main` branch root.
3. After review, add the custom domain `www.bridgetbuildscharacter.com` or `bridgetbuildscharacter.com`.
4. Update DNS only when you are ready to switch the live site.

No custom domain is configured in the repository yet, so the existing live site will not be affected.

## Contact form
The contact form uses `mailto:` and opens the visitor's email application. It does not require a backend and does not store messages on the site.
